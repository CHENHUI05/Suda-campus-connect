# 苏州大学校园网一键连接（Windows）

一个基于 PowerShell 的校园网自动登录 / 断线重连工具。双击即可完成认证，并通过 Windows 任务计划程序实现定时重连与开机自动连接，**无常驻进程、无需管理员权限**。

## 功能特性

- 双击即用：`启动.cmd` 一键登录，`停止.cmd` 一键登出
- 首次启动交互式选择运营商、填写账号密码，自动补全运营商后缀
- 支持有线 / 无线，多网卡时自动选择通往校园网网关的网卡
- 基于 Windows 任务计划：登录时自动连接 + 每 30 分钟定时重连，执行后即退出，不占内存
- 自动记录运行日志，重复启动不会产生多个定时任务
- 纯系统自带组件实现，无需安装任何第三方软件

## 适用环境

- Windows 10 / Windows 11（PowerShell 5.1 系统自带，兼容 PowerShell 7）
- Linux 服务器（bash + cron，见 [`linux/README.md`](linux/README.md)）
- 苏州大学 Dr.COM 类型网关（`10.9.1.3:801/eportal/`），其他同协议高校可自行修改网关地址

## 快速开始

1. 下载本仓库全部文件，放在一个**固定文件夹**中（例如 `文档\校园网`），不要放在临时目录，也不要只移动其中一个文件。
2. 双击 `启动.cmd`：
   - 首次使用按提示选择运营商：`1` 学校校园网、`2` 中国移动、`3` 中国联通、`4` 中国电信
   - 输入账号（**不要**手动加运营商后缀）和密码（输入时不显示）
   - 脚本立即尝试登录，并自动创建定时任务
3. 看到连接成功的提示后，按任意键关闭窗口即可。窗口关闭后定时任务依然生效，以后登录 Windows 也会自动连接。
4. 要停止自动连接并登出校园网，双击 `停止.cmd`。

> 修改文件夹位置前，请先在原位置双击 `停止.cmd`，再移动全部文件并重新启动。

## 文件说明

| 文件 | 作用 |

首次启动后会自动生成 `suda-campus.json`（账号密码配置）和 `运行日志.txt`，两者均已被 `.gitignore` 忽略，不会被提交。

## 配置说明

首次启动的交互信息会保存在同文件夹的 `suda-campus.json`：

```json
{
  "Provider": "中国移动",
  "Username": "20241234567@zgyd",
  "Password": "你的校园网密码",
  "AdapterName": ""
}
```

- **运营商后缀**：选择移动 / 联通 / 电信后，脚本自动追加后缀，对应关系为移动 `@zgyd`、联通 `@cucc`、电信 `@ctc`；学校校园网不加后缀。
- **指定网卡**：一般情况下留空即可。若电脑同时接入多个网络导致选错网卡，把 `AdapterName` 改为实际网卡名称，例如 `"以太网"` 或 `"Wi-Fi"`（可在 Windows「网络连接」页面或 PowerShell 中执行 `Get-NetAdapter` 查看），然后重新双击 `启动.cmd`。
- **密码安全**：密码以明文保存在本机配置文件中，请将文件夹放在个人目录，不要分享 `suda-campus.json`，也不要把它提交到公开仓库。

## 定时任务

- 定时间隔由 `suda-campus.ps1` 开头的 `$IntervalMinutes = 30` 控制，可填写 5–1440 之间的整数，修改后重新双击 `启动.cmd` 生效。
- 任务在当前用户登录时和每隔指定间隔触发，每次执行完即退出，没有常驻轮询进程。
- 可在 Windows「任务计划程序」中看到名为 `SudaCampusGatewayReconnect-...` 的任务，后缀用于区分不同 Windows 用户。
- 电脑睡眠、关机或校园网不可达时无法执行；启动后首次连接失败也会保留任务，稍后自动重试。

## 常见问题

**提示"无法访问校园网网关"？**
请确认已连接校园网网线或 Wi-Fi，并关闭可能拦截请求的 VPN / 代理软件。

**提示"有多个可用地址"？**
在 `suda-campus.json` 中填写 `AdapterName` 指定校园网网卡后重新启动。

**停止时网关未确认登出？**
定时任务此时已移除，不会再自动重连；请登录学校门户手动确认登出。

**窗口一闪而过？**
`启动.cmd` / `停止.cmd` 末尾带有 `pause`，正常情况下会停留；若仍闪退，可在文件夹中打开 PowerShell 执行 `.\suda-campus.ps1 -Action Start` 查看完整报错。
